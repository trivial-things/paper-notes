## 目录约定

- `papers/` — 一篇论文一个 `.md`，文件名 `YYYY-MM-DD-短名.md`
- `assets/` — 图片，按文章名建子目录
- 中文只出现在**标题和正文**里，**文件名一律英文小写加连字符**

## 为什么放这里

只展示结论的文章吸引的是看客；写出「我原来怎么想、后来怎么改」的，才吸引同路人。
